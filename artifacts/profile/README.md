# Профиль горячих путей

Каждый из трёх Criterion-сценариев (`fib_32`, `dedup_10k`, `normalize_65k`) профилировался `perf` в течение 5 секунд. Частота выборки — 997 Гц, сборка — профиль `bench` с отладочными символами.

- до оптимизации: коммит `5bba92d`, 14 976 записей;
- после оптимизации: коммит `92ab711`, 15 029 записей;
- `perf` не потерял данные ни в одном запуске.

## Узкие места до

- `slow_fib`: 33,18% циклов — экспоненциальная рекурсия;
- `slow_dedup`: 16,99% — вложенный линейный поиск дубликатов;
- `core::slice::sort::unstable::ipnsort`: 16,29% — сортировка после каждой вставки;
- `normalize` и связанные копирования: 33,00% — две последовательно создаваемые строки.

## Узкие места после

- `fast_fib`: 31,24% циклов выделенного ему интервала;
- `HashMap::insert`, используемый `HashSet`: 30,48%;
- `normalize`: 32,08%, ещё 1,76% занимает `str::to_lowercase`;
- остальная часть `fast_dedup`: 2,24%.

Профиль подтверждает устранение рекурсивного Fibonacci, повторных линейных проходов и сортировок. Поскольку каждому тесту отведено одинаковое время, проценты на flamegraph показывают структуру профиля, а не соотношение скорости тестов.
